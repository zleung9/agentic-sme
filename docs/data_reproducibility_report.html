4. Structural Reproducibility Issues

Beyond missing files, the manuscript has deeper structural problems that undermine reproducibility.

4.1 Train/Test Leakage

The 338-molecule benchmark set is circular. SMEPre is trained on SMEMol → used to screen generated candidates → validated candidates are added back → SMEPre is retrained and benchmarked on a split of the expanded set. A 9:1 random split on this mixed data evaluates performance on molecules that were selected by an earlier version of the same model. This inflates metrics and is not an independent evaluation.

4.2 Missing Provenance

Legacy CSVs have zero provenance metadata. The my_reg.csv and ss_reg.csv files contain only smiles + class. There is no column for: source type (literature vs generated), anchor group, scaffold ID, data tier, generation round, DFT protocol, or split assignment. The 303 molecules cannot be traced to their origin.

4.3 Inconsistent Naming

Naming conventions are fragmented. Column names vary across files (qi vs label, idx vs Unnamed: 0). Molecule names are inconsistent (SME1 vs Mol7 — the manuscript itself flags this with a placeholder). No canonical molecule ID links the CSV rows to the named Gen/SME molecules.

4.4 Data Duplication Without Documentation

Massive undocumented duplication in large datasets. qi_classification.csv has 7,110 rows but only 227 unique SMILES (32× duplication). ss_seebeck.csv has 1,761 rows but only 46 unique SMILES (38× duplication). These are likely conformer or augmentation duplicates, but this is never documented, making it impossible to know what constitutes an independent sample.

4.5 Incomplete Manuscript (37 Placeholders)

The manuscript is a draft with 37 unfilled placeholders. These include the entire DFT/NEGF protocol, all three conductance values, synthesis routes, filtering statistics, property statistics, 5 missing citations, and 13 incomplete references. The manuscript cannot be submitted in this state.

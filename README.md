# SME-Agent：面向量子干涉单分子电子的物理驱动智能分子共科学家

> 配套文件：请参阅 `MEMORY.md` 获取完整的项目历史、原始手稿参考以及推动本次重建的源对话。

## 项目定位

本仓库正从最初的 **SMEGen** 项目演变为一个面向单分子电子学（SME）的、面向2026年的智能自主发现项目。

旧项目主要将工作框架化为：
> **SMEMol 数据集 + SMEPre 预测器 + LSTM 分子生成器 + DFT/NEGF 验证 + 有限的 EC-STMBJ 实验。**

此框架现被视为**遗留内容**。它应作为历史背景和重要基线被保留，但**并非**最终的科学叙事。

新项目框架为：
> **一个面向量子干涉单分子电子的物理驱动智能分子共科学家。**

项目应从传统的生成-预测-验证循环，转向一个**基于假设驱动的智能自主发现系统**，该系统能够阅读文献、提出量子输运假设、设计分子以验证这些假设、批判候选分子、通过计算进行验证、优先排序合成方案，并支持前瞻性实验验证。

---

## 核心科学论点

单分子电子学并非简单的分子优化任务。它是一个**数据稀疏、机制丰富、实验昂贵的量子输运发现问题**。

新手稿应论证：
> 我们开发了一个面向单分子电子学的智能分子共科学家，它整合了文献知识、量子输运推理、条件分子生成、具有不确定性感知的 DFT+NEGF 验证、逆合成评估和前瞻性 EC-STMBJ 实验。与传统闭环分子优化不同，该系统提出并验证明确的量子干涉假设，从而发现的分子结并非简单外推已知专家设计规则。

关键进展**不是**仅仅使用更新的生成器。关键进展是将稀疏的 SME 知识转化为可验证的、经前瞻性验证的分子器件假设。

---

## 为什么旧框架在2026年已不足够

到2026年，以下简单循环本身已不再具有方法学上的新颖性：

```text
生成 → 预测 → 验证 → 更新
```

这已成为 AI for Science、自驱实验室和分子发现领域的标准范式。

项目必须转而强调：

```text
阅读 → 提出假设 → 设计 → 批判 → 模拟 → 合成 → 测量 → 解释 → 修正
```

系统的评判标准不应仅限于命中率，还应考察其能否：
1. 提出明确的量子干涉假设；
2. 设计分子来验证这些假设；
3. 区分新机制与已知专家规则；
4. 前瞻性地选择正例、负例和对照分子；
5. 解释成功与失败；
6. 建立可审计的推理链条。

## 遗留项目背景

现有项目和手稿使用较旧的命名约定。智能体应了解这些名称，不应盲目删除。

| 遗留名称 | 含义 | 新角色 |
|---|---|---|
| `SMEMol` | 文献来源的 SME 分子数据集 | 种子数据集 / 知识图谱源 |
| `SMEPre` | SME 性质预测器 | 不确定性感知的替代集成组件 |
| `SMEGen` | 基于 LSTM 的生成器及流程 | 历史基线和消融基线 |
| LSTM 生成器 | 原始分子生成器 | 基线，非最终模型 |
| DFT+NEGF 验证 | 计算验证 | 多保真度量子输运智能体工具 |
| EC-STMBJ 验证 | 实验验证 | 前瞻性实验验证模块 |
| 171 个原始分子 | 初始整理数据集 | A 级种子数据 |
| 338 个混合分子 | 原始 + 生成/验证的分子 | 主动学习历史，**非**独立随机划分 |
| Gen1 / Gen9 / SME1 | 已有实验分子 | 遗留实验锚点，不足以作为最终验证 |

### 重要规则

**不要**将遗留的 338 个混合分子集视为干净的独立数据集。后来经过验证的生成分子属于主动学习历史的一部分，必须谨慎处理以避免训练/测试泄漏。

## 系统架构

围绕协作智能体组织新项目，即使某些智能体最初以脚本或模块而非完全自主的 LLM 智能体形式实现。

### 1. 文献-知识智能体

目的：构建可审计的 SME 知识图谱。

职责：挖掘文献来源的分子记录；提取分子结构、锚定基团、骨架类型、结几何构型、电导行为、Seebeck 值、栅极行为和 QI 标签；检测重复结构和不一致标签；将分子与出版物和证据链接；标记无支持的声明或缺失的元数据；维护已知 SME 设计规则的结构化记录。

目标输出：

```text
分子 → 骨架 → 锚定基团 → QI 基序 → 结几何构型 → DFT 标签 → 实验证据 → 来源
```

### 2. 假设智能体

目的：提出并排序机制性的量子输运假设，例如：
- 不对称杂原子位置将反共振移近费米能级；
- 交叉共轭供体-受体基序放大栅极灵敏度；
- 非经典锚定对齐产生隐藏的相消量子干涉通道；
- 杂芳族融合打破预期的魔数比率行为；
- 锚定诱发的能级对齐可主导经典连接性规则。

按以下标准评分每个假设：新颖性、物理合理性、可测试性、DFT 成本、合成可行性、实验可区分性以及与已知专家规则的区分能力。

### 3. 生成设计智能体

目的：生成分子以验证假设，而不仅仅是最大化黑箱得分。

| 角色 | 模型 |
|---|---|
| 主模型 | 条件图扩散 / 图 Transformer 生成器 |
| 强实用基线 | REINVENT4 风格 Transformer/RL 或骨架修饰流程 |
| 低数据基线 | 原始 LSTM / CLM |
| 非 AI 基线 | 随机 SME 类枚举 |
| 专家基线 | 基于规则的量子干涉类似物 |

生成应支持在以下条件下进行条件控制：DQI 存在；高 Seebeck 系数；大调控范围；高调控效率；两个有效锚定基团；合成可及性；骨架新颖性；氧化还原/电化学约束；假设标签。

### 4. 量子输运智能体

目的：管理多保真度计算验证。

```text
图/描述符代理模型
↓
半经验或紧束缚输运（如可用）
↓
DFT+NEGF
↓
几何结构/构象敏感性分析
↓
费米能级对齐不确定性
↓
栅极响应模拟
```

每个计算标签所需的元数据：泛函；基组；赝势；电极模型；Au-锚定几何结构；构象采样规则；费米能级对齐方法；透射谷定义；栅极电压映射；收敛阈值；失败/排除标准。除非计算协议可重现，否则任何结果都不是最终结果。

### 5. 合成智能体

目的：确保生成的分子在实验上是现实的。

职责：计算 SAscore；评估逆合成可及性（如 RAscore、AiZynthFinder）；识别商业前体；估计合成步骤数；检查锚定兼容性；检查氧化还原稳定性和电化学窗口；标记纯化风险；优先选择具有可行路线的分子。不要让美丽但不可合成的分子主导故事。

### 6. 审稿/批判智能体

目的：保护工作免受明显的审稿人攻击。批判者应问：该候选分子是否只是已知 QI 规则的伪装？骨架相对于训练数据是否真正新颖？预测增益是否大于 DFT 不确定性？该分子是否在实验上与对照物可区分？是否存在正例、负例、异构体和专家设计的对照物？审稿人是否会认为这是选择性报告？声称是否强于证据？是否存在训练/测试泄漏的可能？失败的 DFT 或失败的合成案例是否记录在案？生成可在补充信息中使用的审计追溯。

## 数据集策略

### 数据层级

| 层级 | 内容 | 用途 |
|---|---|---|
| A 级 | 原始 SMEMol 文献分子 (171) | 种子数据集 |
| B 级 | 遗留生成 + DFT 验证的分子 | 主动学习历史 |
| C 级 | 已有实验分子 (Gen1/Gen9/SME1) | 遗留实验锚点 |
| D 级 | 新挖掘的文献分子 | 数据集扩展 |
| E 级 | 新生成的前瞻候选分子 | 主动学习候选 |
| F 级 | 锁定前瞻验证集 | 最终测试集 |

### 数据集规则

1. 切勿使用混合遗留+生成数据的简单随机划分作为主要结果。
2. 优先使用骨架划分、来源划分、时间划分和锁定前瞻划分。
3. 先前循环中的生成分子不是独立的外部测试数据。
4. 保留每个分子的完整来源追溯。
5. 记录失败的提取、失败的 DFT 任务、失败的逆合成和失败的合成。
6. 不要隐藏负面或边界候选分子。
7. 使用规范 SMILES 和 SELFIES 标准化分子表示。
8. 明确存储锚定定义。
9. 明确存储骨架和类似物系列标签。
10. 除非使用标准化 DFT+NEGF 流程计算，否则所有标签视为协议相关的。

## 模型与基准计划

### 预测器计划

使预测器成为具有不确定性感知的集成模型，而非单点估计器。

| 任务 | 类型 |
|---|---|
| DQI / 透射谷 | 分类 |
| Seebeck 系数 | 回归 |
| 调控范围 | 回归 |
| 调控效率 | 回归 |
| DFT 失败概率 | 分类 |
| 实验优先级 | 排序 |

推荐的基线：描述符 + Random Forest；描述符 + XGBoost；Chemprop / 消息传递神经网络；GIN/GAT；GraphGPS 或等效图 Transformer；Uni-Mol 或 3D 感知模型（若 3D 输入可靠）；遗留 SMEPre。

所需输出：点预测；不确定性估计；校准诊断；骨架划分性能；锁定测试性能；消融表。

### 生成器计划

主生成器：条件图扩散 / 图 Transformer。

基线：遗留 LSTM；SELFIES Transformer；REINVENT4 风格 Transformer/RL；随机 SME 类枚举；专家规则枚举；基于片段的贝叶斯优化。

生成指标：有效性；唯一性；新颖性；多样性；骨架新颖性；锚定有效性；合成可及性；性质可控性；假设对齐度；匹配预算下的 DFT 命中率；实验优先级率。

### 必要的消融实验

| 消融项 | 问题 |
|---|---|
| 无主动学习 | 循环是否重要？ |
| 无不确定性 | 不确定性是否能改善发现？ |
| 无 DFT 反馈 | 增益是否只是生成器偏差？ |
| 无 SMEPre/代理筛选 | 筛选是否有帮助？ |
| LSTM vs 图扩散 | 新生成器是否重要？ |
| 随机 vs AI | AI 是否优于暴力方法？ |
| 专家规则 vs AI | AI 是否超越了已知设计规则？ |
| 智能 vs 非智能生成器 | 假设引导推理是否有帮助？ |
| 有 vs 无批判智能体 | 批判是否能减少假阳性和审稿人弱点？ |

在**匹配 DFT+NEGF 预算**下，最重要的比较是：

```text
智能假设引导设计
vs 非智能图扩散
vs 遗留 LSTM SMEGen
vs 专家设计/基于规则的类似物
vs 随机 SME 类枚举
```

## 主动学习工作流

```text
生成 50,000–200,000 个分子
↓ 有效性 / 锚定 / 化学筛选
↓ 带不确定性的代理预测
↓ 多样性和新颖性选择
↓ 假设和批判智能体审查
↓ 逆合成 / 合成可行性筛选
↓ 对 50–150 个分子进行 DFT+NEGF
↓ 更新数据集
↓ 重新训练预测器和生成器
↓ 修正假设
```

### 每轮 DFT 的选择策略

| 类别 | 大致比例 | 目的 |
|---|---:|---|
| 利用型 | 40% | 预测性能最高的 |
| 探索型 | 40% | 新颖骨架或高不确定性 |
| 对照型 | 20% | 负例、边界、专家或异构体对照 |

### 推荐轮次

| 轮次 | DFT+NEGF 候选数 | 目标 |
|---|---:|---:|
| 第 0 轮 | 审计/重新计算当前分子 | 建立干净基线 |
| 第 1 轮 | 100–150 | 测试新智能设计 |
| 第 2 轮 | 100–150 | 展示学习改进 |
| 第 3 轮 | 50–100 | 锁定前瞻验证 |

最后一轮必须在 DFT/实验之前冻结。不要追溯修改验证集。

## 给 Claude Code 的实施指南

### 在新会话中的首要操作

1. 首先阅读 `MEMORY.md` 了解完整的项目历史和源文件。
2. 检查仓库目录树。
3. 识别遗留 SMEGen 文件、数据、笔记本和手稿文件。
4. 查找现有命名约定。
5. 避免破坏性编辑。
6. 创建从遗留流程到新智能架构的迁移映射。
7. 提议小的、可审查的提交。

### 编码规则

- 优先使用模块化、可测试的 Python 代码。
- 除非明确要求删除，否则保持遗留代码的正常工作。
- 将新的智能体代码放入清晰分离的模块中。
- 对模型选择、阈值和数据集路径使用配置文件。
- 保持所有随机种子的显式性。
- 记录所有生成的、拒绝的、失败的和选择的分子。
- 存储智能体决策的审计追溯。
- 切勿覆盖原始数据。
- 切勿编造结果。
- 将未知结果标记为 `TBD`、`pending` 或 `not_yet_run`。
- 除非存在支持数据，否则不要在手稿文本中做出声明。

## 声称纪律

在存在匹配证据之前，**不要**写：
- "优于专家设计" — 需要匹配预算下的专家规则与 AI 比较；
- "发现新机制" — 需要假设、对照、DFT 支持和实验支持；
- "稳健预测器" — 需要不确定性/校准/骨架划分结果；
- "实验验证的平台" — 需要足够多的前瞻性分子已测量；
- "自主的" — 需要真正的规划/工具使用而无隐藏的人工选择。

在证据存在之前更安全的措辞："候选框架"、"工作假设"、"前瞻验证目标"、"初步 DFT 支持"、"设计用于测试"、"旨在区分"、"待实验验证"。

## 审稿人风险登记表摘要

1. **系统只是标准闭环。** → 强调智能假设生成、批判和测试设计。
2. **AI 没有因果贡献。** → 与随机、专家、LSTM 和非智能图扩散基线比较。
3. **数据集太小。** → 扩展文献数据和 DFT 标记的前瞻候选；报告不确定性。
4. **训练/测试泄漏。** → 使用层级数据、骨架/来源/时间/前瞻划分。
5. **DFT+NEGF 标签不可重现。** → 标准化并记录完整的计算协议。
6. **生成的分子不可合成。** → 包含逆合成和实验可行性筛选。
7. **实验验证太薄弱。** → 包含 8–15 个分子，包括正例、负例、专家对照和异构体对照。
8. **机制不新。** → 需要假设新颖性分析和针对已知 QI 规则的对照。
9. **手稿过度声称。** → 维护声称-证据追溯。

## 完成的定义

在以下所有内容存在之前，尚不适合向顶刊投稿：

- 具有来源追溯的干净标准化数据集；
- 无泄漏的训练/验证/测试划分；
- 可重现的 DFT+NEGF 协议；
- 具有不确定性感知的预测器集成；
- 现代生成器及强基线；
- 智能假设生成和批判日志；
- 与随机、专家、LSTM 和非智能基线的匹配预算比较；
- 至少一轮前瞻性 DFT；
- 包含正例、负例和对照的实验验证；
- 声称-证据对照表；
- 代码/数据可用性计划；
- 审稿人风险登记表；
- 围绕智能假设驱动发现重写的手稿。

## 偏好的工作风格

对科学声称保持保守；对识别方法论弱点保持积极；保留有用的遗留工作作为基线；区分证据与愿景；询问每个结果证明的是模型新颖性、领域新颖性还是机制新颖性；优先考虑可重现性和可审计性；偏好小型、可审查的变更；在编写代码的同时编写文档；将失败的候选视为科学上有用的数据。

目标不是让旧 SMEGen 手稿看起来更新。目标是重建项目，使最终论文真正与 2026 年的智能 AI for Science 时代对齐。
